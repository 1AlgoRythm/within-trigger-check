Trigger check for Within

Within's console can test what Within answers ("Try a question"). This tests whether the agent asks Within at all. Each prompt runs in a fresh Claude session connected to a demo vendor MCP server ("Acme") with @getwithin/sdk installed. A buying question should make Claude call get_vendor_answer. Everything else should not.
